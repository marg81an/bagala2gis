# Bagala — QR-отзывы для заведений (RU / KZ)

Гость сканирует QR на столе → ставит оценку 1–5 ⭐.
- **4–5 ⭐** → гостя сразу перекидывает на страницу отзывов в 2ГИС (или Google, если 2ГИС не указан). Если ссылок нет — просто «Спасибо!».
- **1–3 ⭐** → форма «Что пошло не так?» → жалоба сразу приходит владельцу в Telegram. Ссылка на 2ГИС тоже остаётся (мелко), чтобы не нарушать правила площадок.

Владелец видит кабинет со статистикой, а ты управляешь всеми заведениями в админке.

## Что внутри
| Адрес | Что это |
| --- | --- |
| `/` | Лендинг для продаж |
| `/r/<slug>` | Страница оценки для гостя (RU/KZ). `?s=Имя` — QR конкретного сотрудника |
| `/d/<токен>` | Кабинет владельца (секретная ссылка, без пароля) |
| `/admin` | Твоя админка: заведения, ссылки, QR, Telegram |
| `/admin/print/<slug>` | Табличка с QR для печати (A6, два языка) |
| `/api/telegram` | Вебхук бота: подключение чата, команда `/stats` |

Без npm-зависимостей: Node.js 18+, база Supabase, хостинг Vercel (всё бесплатно на старте).

---

## Запуск на своём компьютере (5 минут, без настроек)
1. Установи [Node.js](https://nodejs.org) (версия 18 или новее).
2. В папке проекта выполни: `npm run dev`
3. Открой http://localhost:3000/admin, пароль `admin`.
4. Создай заведение → открой «Страница» и «Кабинет».

Данные сохраняются в `.data/dev-db.json`. Telegram в этом режиме просто пишет сообщения в консоль.

## Публикация в интернет

### Шаг 1. База данных (Supabase)
1. Зарегистрируйся на https://supabase.com → **New project** (регион: Frankfurt или ближайший).
2. Слева **SQL Editor** → **New query** → вставь содержимое `supabase/schema.sql` → **Run**.
3. **Project Settings → API**: скопируй **Project URL** и **secret** (или `service_role`) ключ.
   ⚠️ Секретный ключ никому не показывай и не вставляй в код.

### Шаг 2. Telegram-бот
1. В Telegram открой **@BotFather** → `/newbot` → придумай имя, например `BagalaKZ_bot`.
2. Скопируй **токен** и **username** бота.

### Шаг 3. Хостинг (Vercel)
1. Загрузи проект на GitHub (новый репозиторий → **Upload files** → перетащи все файлы, кроме `.data` и `.env`).
2. Зайди на https://vercel.com → **Add New → Project** → выбери репозиторий.
3. В **Environment Variables** добавь (пример в `.env.example`):

| Переменная | Значение |
| --- | --- |
| `SUPABASE_URL` | Project URL из шага 1 |
| `SUPABASE_SERVICE_ROLE_KEY` | secret-ключ из шага 1 |
| `ADMIN_PASSWORD` | твой пароль для `/admin` |
| `SESSION_SECRET` | любая длинная случайная строка |
| `TELEGRAM_BOT_TOKEN` | токен из шага 2 |
| `TELEGRAM_BOT_USERNAME` | username бота без `@` |
| `TELEGRAM_WEBHOOK_SECRET` | любая строка из латиницы и цифр |
| `TIMEZONE` | `Asia/Almaty` |

4. **Deploy**. Получишь адрес вида `https://bagala.vercel.app`.

### Шаг 4. Включить бота
Открой `https://твой-сайт/admin` → войди → нажми **«Подключить вебхук бота»**. Должно появиться «Вебхук подключён ✅».

### Шаг 5. Первое заведение
1. В админке **«Добавить заведение»**: название + ссылка на 2ГИС.
   Ссылку берёшь так: открываешь карточку заведения на 2gis.kz → вкладка «Отзывы» → копируешь адрес из браузера.
2. Нажми **QR** → распечатай табличку (можно сделать отдельный QR на каждого сотрудника).
3. Отправь владельцу ссылку на **Кабинет**. Там он сам нажмёт «Подключить себе» (или «в группу») — и жалобы начнут приходить в Telegram.

Свой домен (например `bagala.kz`): Vercel → Project → **Settings → Domains**.

## Полезно знать
- Владелец потерял ссылку на кабинет или её увидел кто-то лишний → в админке «Изменить» → «Выдать новую ссылку на кабинет».
- Чтобы бот писал не только жалобы, а все оценки — галочка «Присылать в Telegram все оценки».
- Команда `/stats` в Telegram — сводка за 7 дней.
- Не обещай клиентам «скрыть плохие отзывы»: 2ГИС и Google это запрещают. Продавай так: **«узнавайте о проблемах первыми и решайте их сразу»**.
